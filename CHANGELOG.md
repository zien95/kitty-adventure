# Changelog

## v26.9.1 - Pet Fiasco (2026-10-15)

- Replaced synthesized pet calls with licensed real cat, dog, bunny, fox, panda,
  and bird recordings, with an in-app Creative Commons credits page.
- Rebranded to Pet Fiasco with the new pet-fiasco.web.app address.
- Added Firebase email/password accounts, password reset, private Firestore saves, and restore choices.
- Added conflict detection to prevent silent cloud overwrites from another device.
- Added pet day counters, age in days, and age-or-level evolution with a growth guide.
- Removed anniversary branding and its gift code; refreshed the Secrets journal with visible clues and a new growth discovery.
- Added species eggs with a persistent two-minute incubation timer and one-time hatch/adoption into the pet family.

- Added 57 original synthesized effects across Cute Voices, Soft Cozy, and Arcade themes.
- Added frequent care, pet, reward, navigation, job, and secret sound feedback.
- Added separate effects/music volume, six music tracks, mood-based music, and background pause.
- Added per-pet daily care checklists, varied-care combo rewards, and birthday celebrations.
- Added care reaction bubbles and happy hops.
- Fixed the first-run tour starting behind the daily reward dialog.
- Fixed tutorial highlighting on initial layout and scrolling at large text sizes or short heights.
- Packaged the existing Pet Parade, Animal Almanac, habitat boosts, and racing improvements for all platforms.

## v26.9.0 - Pet Parade Update

- Added Pet Parade so the whole pet family can march together.
- Added Animal Almanac with species habitats and boost details.
- Added habitat boosts for cats, dogs, bunnies, foxes, pandas, and birds.
- Added a daily streak card with tomorrow's reward preview.
- Added sound packs: Classic, Soft, Arcade, and Quiet.
- Balanced racing so high levels are fairer with tap spam or hold-space sprinting.
- Added clearer saved feedback after care, profile, room, outfit, job, and code actions.
- Bug fixes.
